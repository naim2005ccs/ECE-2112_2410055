# About This Repository

This repository contains the laboratory reports, circuit designs, simulation files, and related resources prepared for the Digital Logic Design Laboratory course offered by the Department of Electrical & Computer Engineering, Rajshahi University of Engineering and Technology (RUET).

Each experiment includes:

- Objective
- Theory
- Circuit Diagram
- Truth Table
- Working Principle
- Simulation Result
- Observation
- Conclusion

The circuits are designed and verified using Logisim Evolution.
